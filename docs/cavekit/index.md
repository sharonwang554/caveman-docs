# Cavekit

**compressed spec-driven development for claude code**

Cavekit is the simplest full loop: **grill → spec → research → review → build**, over one `SPEC.md` file, no sub-agents. 

It uses a **durable spec** (the agent's long-term memory) and **caveman encoding** (~75% fewer tokens than prose) to streamline development.

Use the sidebar to explore Cavekit's commands and skills.
